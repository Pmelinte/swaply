# Swaply

Minimal i18n foundation with LanguageSwitcher (RO/EN) and cookie-based locale persistence.

## What’s included
- Romanian as default language, English as secondary
- Language switcher in the header
- Locale persisted in a cookie
- No URL changes (routes remain `/`, `/login`, `/signup`)

## Local development
```bash
pnpm install
pnpm dev
```

## Notes
- If Google Fonts are blocked in CI, the app falls back to system fonts.
