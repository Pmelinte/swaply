# Info City — Saved Artifacts

This folder stores files copied or exported from the Info City application.

Structure
- notes.md — free-form notes and excerpts (also linked from `docs/info-city-notes.md`)
- raw/ — raw files (screenshots, exported JSON, SQL snippets)
- summaries/ — short summarized extracts

Provenance
- Always add a short note with: source, date, and any relevant context.

How to use
1. Paste or upload files into `docs/info-city/raw/`.
2. Add a one-paragraph summary into `docs/info-city/summaries/`.
3. Link both from `docs/info-city-notes.md`.
